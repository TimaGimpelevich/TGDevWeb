# Freelance Portfolio

Готовый сайт-портфолио для старта во фрилансе.

## Что внутри

- Главная страница с позиционированием, услугами, ценами и контактами.
- 4 демо-кейса в отдельных страницах:
  - `projects/dentacare.html`
  - `projects/neon-burger.html`
  - `projects/shoplite.html`
  - `projects/legalpro.html`

## Запуск локально

Открой `index.html` в браузере или запусти простой сервер:

```bash
cd /Users/timofeygimpelevich/freelance-portfolio
python3 -m http.server 5500
```

После запуска открой `http://localhost:5500`.
